GMAIL STORAGE TREEMAP 1.1 · LOCAL WINDOWS APP

Your Gmail, mapped by size.

Double-click Start-Gmail-Storage-Treemap.cmd in this folder. Choose Demo to try the treemap, or complete the one-time Google setup below to scan your mailbox.

Gmail Storage Treemap requests Gmail metadata permission: headers, labels and message size estimates. It cannot read message bodies or attachments, send mail, or delete mail. Your metadata stays in the local app. Sign-in tokens stay in memory and disappear when it closes.

One-time Google setup

  1. Open Google Cloud Console and create a project named Gmail Storage Treemap Personal, or select your existing personal project.
  2. Open the Gmail API page, select that project, and enable the API.
  3. Open Google Auth Platform. Complete the app branding/contact details. For a personal Gmail account choose External audience, keep it in Testing, and add your own Gmail address under Audience → Test users.
  4. Under Data Access, add the scope https://www.googleapis.com/auth/gmail.metadata. Do not add send, modify or full-mail access.
  5. Under Clients, create an OAuth client with application type Desktop app. Download its JSON file. A web-app client will not work with Gmail Storage Treemap.
  6. In Gmail Storage Treemap, click Connect Gmail… and select the downloaded JSON. Sign in through Google's browser page using the Gmail address you added as a test user, review the requested permission, and grant it if it matches the scope above.

Google may identify your personal test app as unverified. Check the project and app name yourself. If Google or your Workspace administrator blocks access, resolve that configuration before continuing; Gmail Storage Treemap cannot override it.

The app lists every message, including Spam and Trash, and retrieves size metadata. A progress dialog shows the current phase, message count, percentage and elapsed time. While listing the mailbox, it shows the number found; the percentage becomes available once listing finishes. Use Scan progress… to reopen a hidden dialog.

Gmail Storage Treemap budgets 4,800 API quota units per minute, allowing up to about 4 message reads per second under Google's current limits. A large mailbox can take hours. If Google asks it to slow down, all workers pause for at least 65 seconds (or Google's requested wait), then resume more slowly. The dialog displays the cooldown. Keep the app open. Stop scan keeps collected messages and marks the result partial.

Recovering from the earlier quota error: click OK in the old app and use Save snapshot if results were collected. Close the old app and reopen Start-Gmail-Storage-Treemap.cmd; its title now says Gmail Storage Treemap 1.1. Open the saved snapshot, then choose Resume scan…, select the same OAuth client JSON, and sign into the same Gmail account. If there are no collected results, use Connect Gmail… for a fresh scan. Your Google project and credentials do not need to be recreated.

Explore your mailbox

  • Group by Sender, Domain, Year, Location, or Label set. Click a tile or select a group to see its messages. Click All mail to return.
  • Larger rectangles represent more bytes. Hover for details. The list beneath the map is sorted largest first. Clicking a message tile selects it in the list.
  • Use Find to match sender, subject or labels, and the size filter to isolate large messages.
  • Select a message, then choose Open selected in Gmail to review it in Gmail.
  • Save snapshot stores message metadata locally so you can reopen it without another scan. The file includes senders and subjects; keep it private. It contains no access or refresh tokens.
  • Resume scan… continues an incomplete Gmail snapshot. It lists the mailbox again, drops records no longer present, and retrieves only messages missing from the snapshot. Reused entries retain their previously scanned labels and sizes; choose Connect Gmail for a fresh scan of everything.
  • Export visible CSV includes all messages matching the current filters and group, across every list page.

How the totals work

Gmail's API supplies sizeEstimate per message. These totals are estimates of message size, including encoded content, and can differ from Google's billed storage quota. Gmail Storage Treemap does not inspect attachment contents or report attachment-only size. The mailbox can also change during a scan.

Messages with several labels are counted once. Label set groups by the complete combination of labels. Location assigns each message once, using this order: Trash, Spam, Drafts, Sent, Inbox, then Archived / other.

A treemap displays the 160 largest groups or messages, plus an Other tile. That tile includes all remaining bytes and can be opened to explore them. Zero-byte records remain in the list.

Connection troubleshooting

  • Quota / per-minute limit (403 or 429): Gmail Storage Treemap waits and retries automatically. This limit controls scanning speed, not Gmail storage capacity. Run one scan at a time. If quota remains unavailable after repeated waits, save the partial snapshot and resume later. There is no need to add billing or increase quotas for ordinary scanning.
  • Access denied / other 403: confirm the Gmail API is enabled, your email is a test user, and your organization permits the app.
  • Invalid client: download credentials for a Desktop app, not a web application.
  • Timeout: retry Connect Gmail and finish browser sign-in within five minutes. Allow the local callback on 127.0.0.1.
  • Partial scan: a stopped scan or unavailable message is explicitly marked partial. Save it before closing the app, then use Resume scan to continue. Snapshots are not automatically refreshed or saved.
  • To revoke permission, open Google Account connections and remove the personal app.

As an offline fallback, Open snapshot also accepts one extracted .mbox file from Google Takeout. MBOX sizes describe exported bytes, not server quota. Import one All Mail export to avoid duplicates from separate label exports.

Files and requirements

Requires Python 3.10+ with Tkinter. No pip packages, hosted service or subscription. Keep gmail_storage_treemap.py, gmail_storage_core.py, Setup.html and the launcher together. Nothing is saved automatically.

Reference: Gmail message size estimates, Gmail scopes, Google Desktop OAuth, current Gmail API quotas.
